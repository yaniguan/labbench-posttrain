# BioProBench samples

Source: [YuyangSunshine/bioprobench](https://github.com/YuyangSunshine/bioprobench) (also linked as bioprotocolbench).

License: CC BY-NC 4.0. This data is not MIT. Do not relicense it.

This folder has the public test splits and a 500-row train sample for PQA, ORD, ERR, and GEN.

`bash scripts/get_bioprobench.sh` downloads the full train splits from the Hugging Face dataset `BioProBench/BioProBench` and replaces the 500-row train files.
