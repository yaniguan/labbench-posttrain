# Protocol-reasoning result summaries

These files are copied from the completed run that compared Haiku 5.5, GPT 6 Luna, and GLM 5.3 flash. They were not recomputed in this repo.

Raw per-question model outputs are not included. `labeval.analyze` and `labeval.budget` need those raw files, so they cannot rebuild these summaries from this checkout.

- **Note on `rl_summary_grpo.json`:** despite the legacy filename, `rl_summary_grpo.json` is **not** a trained GRPO policy result. It is the `k=4` temperature-1.0 sampling variance probe generated before training by `python -m bioenvs.baseline --k 4 --temperature 1.0 --tag grpo`. Future sampling probes default to `--tag k4` (`rl_summary_k4.json`); the historical numbers in `rl_summary_grpo.json` and the other completed-run JSON files are left unchanged.
- **Run metadata (`meta`) & offline audit artifacts:** new JSON reports generated by `labeval.analyze`, `labeval.budget`, `labeval.shortcuts`, `bioenvs.baseline`, `scripts/check_overlap.py`, and `posttrain.eval_suite` include a `"meta"` provenance block (`common/run_meta.py`) recording git commit, dirty state, input file SHA-256 hashes, prompt template hash, reward version, sampling parameters, library versions, and UTC timestamp. `labbench_shortcuts.json` (from `python -m labeval.shortcuts`) and `bioprobench_overlap.json` (from `python scripts/check_overlap.py`) are deterministic offline evaluations on the checked-in files.

LAB-Bench questions are in `data/labbench` (CC-BY-SA-4.0). Do not train on that data. BioProBench prompts are in `data/bioprobench` (CC BY-NC 4.0).
