# Protocol-reasoning result summaries

These files are copied from the completed run that compared Haiku 5.5, GPT 6 Luna, and GLM 5.3 flash. They were not recomputed in this repo.

Raw per-question model outputs are not included. `labeval.analyze` and `labeval.budget` need those raw files, so they cannot rebuild these summaries from this checkout.

LAB-Bench questions are in `data/labbench` (CC-BY-SA-4.0). Do not train on that data. BioProBench prompts are in `data/bioprobench` (CC BY-NC 4.0).
